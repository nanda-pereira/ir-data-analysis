# ir-data-analysis

repositório de estudos e projetos práticos aplicando análise de dados com Python ao contexto das **Relações Internacionais** e do **Comércio Exterior (Trade Analytics)**.

### | sobre o projeto
acervo documental da exploração técnica, unindo tecnologia e análise internacional, explorando dados inspirados em bases abertas (como o Comex Stat / MDIC) para investigar fluxos bilaterais, balança comercial e dinâmicas entre parceiros estratégicos.

### | ferramentas
* **Python** - Google Colab
* **Pandas** - manipulação e agrupamento de dados
* **Matplotlib** - visualização gráfica
* **Streamlit** - dashboards interativos
